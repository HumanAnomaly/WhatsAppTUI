# Demo assets

Sample media used by `pnpm run demo`. Not required at runtime — the demo falls back to text placeholders when these files are missing.

- `golden-hour.png` — "Golden hour at bekol savannah" by Candra Firmansyah, via Wikimedia Commons: <https://commons.wikimedia.org/wiki/File:Golden_hour_at_bekol_savannah.jpg> — licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Resized to 640px for the terminal preview.
- `voice-note.wav` — generated locally with Windows SAPI text-to-speech, no external source.
